# Life Fertility Centre, Malda

Website and online consultation booking for Dr. Debchandan Roy, Life Fertility Centre
(gynaecology, fertility/IVF, pregnancy care). Next.js 16, React 19, Tailwind 4, Zod, Prisma.
Local only: not deployed.

Built from a copy of the LittleBloom app; same colour tokens, new design (see `DESIGN.md`).

## Run

```bash
npm install
npx prisma generate      # npm 11 skips install scripts, so run this by hand
npm test                 # booking engine tests (15)
npm run dev              # http://localhost:3103
npm run build            # production build
```

With `DATABASE_URL` empty the app runs in **demo mode**: in-memory store seeded from
`src/content/seed.ts`, mock payment checkout, emails logged to the console. Copy
`.env.example` to `.env.local` to configure Postgres, Razorpay and Resend.

Database: `npm run db:migrate` then `npm run db:seed` (needs `DATABASE_URL`).

## Where things are

| | |
|---|---|
| Public facts (phone, hours, fee, links, legal text) | `src/content/facts.ts` |
| Treatments (13 pages) | `src/content/treatments.ts` |
| FAQs | `src/content/faqs.ts` |
| Notices ticker | `src/content/notices.ts` |
| Photos / portrait | `src/content/photos.ts`, `public/photos/` |
| Schedule, fee, advance, slot size, LFC reference prefix | `src/core/content/base-seed.ts` |
| Booking engine, validation, payments, store | `src/core/` (see `docs/ARCHITECTURE.md`) |

Pages: `/`, `/about`, `/treatments`, `/treatments/[slug]`, `/fertility`, `/pregnancy`,
`/appointment`, `/appointment/confirmation`, `/urgent`, `/contact`, `/faq`,
`/privacy-policy`, `/terms`, `/cancellation-refund`, plus sitemap, robots, OG/Twitter images.

Booking: consultations only, 5 visit reasons (gynae, fertility, pregnancy, follow-up, second
opinion). Mon–Sat 10:00–14:00, 5-minute slots, 1 per slot, next 7 days (today included), ₹200 advance of
the ₹650 fee. References look like `LFC-261114-641WE`. Emergency booking is off; `/urgent`
tells patients to call or go to hospital.
